# Slime-VR-Toolbox

A work-in-progress tool for changing how trackers interact with the SlimeVR Server.

Built using a modified version of the [Godot Engine](https://github.com/CookyHD/GodotEngine-Cookys-Additions) (See Below).

## Custom Engine

[Godot Engine Cooky's Additions](https://github.com/CookyHD/GodotEngine-Cookys-Additions) by [CookyHD](https://github.com/CookyHD).
